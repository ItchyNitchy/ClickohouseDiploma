
# Формирование отчета по санитарной очистке населенных пунктов

Дипломный проект в рамках обучения по курсу clickhouse для инженеров и архитекторов БД

## Цель работы
* Исходными данными для работы являются утвержденные формы и методики заполнения отчета о “Cанитарной очистке населенных пунктов”, установленные постановлением Министерства жилищно-коммунального хозяйства Республики Беларусь 28.11.2022 № 13.
* Целью является автоматизация процесса сбора и обработки данных для формирования отчета.
* В рамках данной работы было реализованно заполение раздела №4 “Объекты сортировки и переработки твердых коммунальных отходов” и приложения №3 “Об объектах сортировки, использования и захоронения твердых коммунальных отходов”.

## Технологии
* Хранение данных:  PostgreSql, clickhouse
* UI: Vue.js
* Backend .NET Web Api

### Шаги развертывания
* Для запуска и развертки структуры БД оформлен docker compose с Makefile. Из папки docker выполнить:
```
make up
```

* Для запуска Web UI (будет доступен по адресу http://localhost:9000/#/) - из папки web выполнить:
```
npm install
quasar dev
```

* Для запуска Web Api - из папки back\sanitation_web_api выпонить:
```
dotnet run
```
